# Landing Page Institucional — Integração com API do YouTube

Landing page desenvolvida para advogado com canal ativo no YouTube, com o objetivo de fortalecer a presença digital, aumentar a credibilidade profissional e divulgar conteúdos audiovisuais diretamente no site.

## 💡 Problema
Muitos sites institucionais apresentam apenas informações estáticas, o que dificulta transmitir autoridade e engajamento. No caso de profissionais que produzem conteúdo em vídeo, a ausência dessa integração reduz o potencial de alcance e confiança do público.

## 🛠️ Solução
Desenvolvimento de uma landing page institucional que consome a API do YouTube para exibir dinamicamente os vídeos mais recentes do canal do cliente, reforçando sua autoridade e conectando o site à produção de conteúdo já existente.

A integração foi pensada para ser simples, objetiva e focada em credibilidade, sem sobrecarregar o usuário com informações excessivas.

## ⚙️ Funcionalidades
- Integração com a API do YouTube Data v3
- Exibição dinâmica dos vídeos do canal
- Paginação de resultados
- Layout responsivo
- Animações suaves para melhorar a experiência do usuário
- Navegação clara e focada em conversão

## 👩‍💻 Minha contribuição
- Desenvolvimento completo da landing page em HTML, CSS e JavaScript
- Integração com a API do YouTube via requisições HTTP
- Implementação de lógica de paginação dos vídeos
- Organização do código e manipulação do DOM
- Decisões de UX voltadas à credibilidade e clareza da informação
- Implementação de animações e efeitos de scroll

## 🔐 Segurança e boas práticas
A integração com a API do YouTube utiliza uma API Key com restrições de domínio configuradas no Google Cloud Console, garantindo que a chave funcione apenas no domínio da aplicação.

Por motivos de segurança, a chave não é versionada no repositório público.

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript
- YouTube Data API v3

## 📎 Contexto
Projeto desenvolvido como trabalho freelance para cliente real, com foco em presença digital, autoridade profissional e integração com plataformas externas.
